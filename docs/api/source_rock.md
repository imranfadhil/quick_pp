# Source Rock & Total Organic Carbon (`quick_pp.source_rock`)

Organic-rich source rock identification and continuous Total Organic Carbon (`TOC`, wt%) quantification via Passey et al. (1990) $\Delta\log R$ resistivity-porosity separation (`passey_delta_log_r`), automated lean-shale baseline detection (`auto_detect_shale_baseline`), Hood et al. (1975) Level of Organic Metamorphism (`LOM`) thermal maturity conversion from $R_o$ (%) (`hood_ro_to_lom`, `hood_lom_to_ro`), and linear core pyrolysis TOC calibration (`calibrate_toc_to_core`).

::: quick_pp.source_rock
