# Log Blocking & Static-to-Dynamic Upscaling (`quick_pp.upscaling`)

Petrophysically rigorous well log blocking (`block_logs`, `upscale_logs`) onto cellular geomodel grids with thickness-weighted arithmetic porosity/shale averaging, pore-volume weighted saturation averaging (preserving bulk hydrocarbon volume `BVHC`), directional & Cardwell-Parsons (1945) permeability bounds ($k_h, k_{\text{eff}}, k_v, k_v/k_h$), and majority-vote facies upscaling.
