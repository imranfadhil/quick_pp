# Probabilistic Uncertainty & Monte Carlo Engine (`quick_pp.uncertainty`)

Vectorized Latin Hypercube Sampling (`scipy.stats.qmc.LatinHypercube`) for log-level CPI uncertainty propagation (`run_cpi_uncertainty` / `run_log_uncertainty` producing `P10`/`P50`/`P90` logs), stochastic volumetric STOIIP/GIIP Monte Carlo (`mc_volumetric_uncertainty`), and probabilistic reservoir summaries (`calc_stochastic_reservoir_summary`).
