## 3. Main "About My Open Source Work" Profile

*Paste this into the main Markdown editor on your GitHub Sponsors dashboard:*

### Why I Build Open-Source Subsurface Tools

Subsurface evaluation and petrophysical interpretation shouldn't always require heavyweight, black-box commercial software just to run a reproducible multi-well workflow. 

I started developing **[`quick_pp`](https://github.com/imranfadhil/quick_pp)** as an independent, open-source Python library to make petrophysical interpretation, well log processing, multi-mineral solving, and machine learning experimentation fast, transparent, and scriptable. Whether you are a student working on public datasets, a researcher benchmarking carbonate and clastic models, or a practicing geoscientist automating routine log evaluations, `quick_pp` is built to give you a clean, Python-native toolkit.

### Where Your Sponsorship Goes
Maintaining an open-source scientific package—writing documentation, validating physical equations, testing across new Python releases, and building real-world notebook examples—takes steady evening and weekend effort. 

Your support directly fuels:
* **Core Maintenance & Stability:** Keeping dependencies lightweight, squashing bugs, and maintaining clean API design.
* **New Petrophysical & ML Modules:** Expanding rock-typing workflows, multi-mineral solvers, permeability estimation, and uncertainty quantification routines.
* **Applied Tutorials & Benchmarks:** Creating practical, end-to-end Jupyter notebooks on public subsurface datasets so students and practitioners can learn applied geoscience coding hands-on.

Every contribution—whether a one-time coffee after `quick_pp` helped you hit a deadline or an ongoing monthly sponsorship—helps keep open-source petrophysics thriving. Thank you for being part of the community!

- [ ] Copy the profile bio and tier descriptions above into your GitHub Sponsors dashboard.
